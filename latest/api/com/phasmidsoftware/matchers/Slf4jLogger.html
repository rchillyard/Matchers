Slf4jLogger

com.phasmidsoftware.matchers.Slf4jLogger
case class Slf4jLogger(logLevel: LogLevel, logger: Logger) extends MatchLogger

A case class that wraps SLF4J logging functionality, extending MatchLogger to utilize a specified logging level and SLF4J logger instance for log operations.

Value parameters

logLevel

The logging level to control the behavior of the logger, determining whether logs are written based on the specified level (e.g., LogInfo, LogDebug).

logger

The SLF4J Logger instance used for performing the logging operations. The class delegates the actual logging operations to SLF4J's Logger methods based on the provided logging level: - Logs at the info level if the logLevel is LogInfo. - Logs at the debug level if the logLevel is LogDebug. - Skips logging for other levels. Inherits functionality from MatchLogger, allowing it to act as a functional logger with behavior controlled by the specified logLevel.
