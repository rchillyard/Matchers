class MatchLogger(val logLevel: LogLevel, f: String => Unit) extends String => Unit

A logger class for handling and managing logging operations based on the specified log level.

Value parameters

f

A function that takes a string input and performs the logging operation.

logLevel

The logging level to determine the behavior of the logger (LogOff, LogInfo, LogDebug).

Attributes

Constructor

Creates a new MatchLogger instance with a given log level and a logging function.

Note

The class extends String => Unit, enabling it to be used directly as a function.
